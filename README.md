# number-base-converter
A number base convertor that converts positive decimal integers into Binary, Hexadecimal, Octal, and 4-bit Binary-Coded Decimal (BCD).

# Features
**Number Base Conversions:** Decimal (`base-10`) to Binary (`base-2`), Hexadecimal (`base-16`), and Octal (`base-8`)
**BCD Encoding:** Converts each decimal digit into its 4-bit binary nibble representation
**Dual Interfaces:**
  - `converter.py`: Interactive terminal version with continuous input loop
  - `converter_gui.py`: Interface built with `tkinter`
